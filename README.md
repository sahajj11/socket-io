# Socket.IO + React Learning Project 🚀

This repository contains my **learning experiments** with **Socket.IO** for building **real-time web applications** using **React** as the frontend.

---

## 📝 About

This project is focused on understanding **real-time, bidirectional communication** between a frontend and a backend using **Socket.IO**.  
So far, the backend is built with **Node.js + Express + Socket.IO**, and the frontend is planned in **React**.

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express, Socket.IO  
- **Frontend:** React (planned)  
- **Others:** CORS
